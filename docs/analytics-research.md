# Analytics research, 23 October 2026

The owner chose detailed aggregate traffic and engagement in the existing private dashboard, without visitor identifiers. Extend the existing Workers/D1 collector rather than add another service/login. This is a small purpose-built collector, not an equivalent to the full capabilities or operational maturity of these projects. No upstream code was copied.

## GDPR and consent scope

Cookie-free does not automatically mean GDPR compliant or exempt from consent. [AEPD's audience-measurement guide](https://www.aepd.es/guias/guia-cookies-analiticas-externas.pdf) limits exemption to specified measurements and anonymous statistics, with notice, retention and processor safeguards. The portfolio says Portsmouth: the current [ICO statistical-purposes exception](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/what-are-the-exceptions/) also requires clear information and a simple/free objection mechanism. Its [storage/access guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/what-are-storage-and-access-technologies/) covers scripts accessing device information, even without cookies.

The implementation supplies bounded site measurements, a public notice, GPC/DNT handling and an explicit opt-out. Intended legitimate interests for necessary personal-data processing must be supported by the owner's documented necessity/balancing assessment. Before expanding production collection, confirm applicable jurisdictions, Cloudflare processor terms and transfer safeguards, and actual infrastructure logging/retention. Cloudflare network processing and existing D1 residency have not been independently audited. No EU-only processing guarantee or legal certification is made.

An independent Cloudflare Web Analytics script can be injected outside this Git repository. The production page open during review loaded `https://static.cloudflareinsights.com/beacon.min.js/...`. Disable that beacon or align its preferences before calling the opt-out site-wide. Turnstile/contact processing remains separate. Small aggregate counts remain owner-only and must not be joined with the contact inbox.

No unique/returning visitors, bounce rate, sessions, individual funnels, campaign IDs, heatmaps or recordings are added. No IP hashes. Sources use coarse fixed categories. Blockers, interrupted networks, shared-IP limits, quotas and forged telemetry still affect completeness. See [implementation and rollout](analytics-implementation.md).
