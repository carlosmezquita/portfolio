Surfay

Personal project · Working prototype

I built the map interface and backend that turn marine forecasts and local coastal profiles into hourly spot forecasts for Galicia.

The engineering notes explain how the backend keeps spot updates and forecast snapshots in sync and preserves the forecast behind each condition report.

React, TypeScript, MapLibre · Cloudflare Workers & D1
