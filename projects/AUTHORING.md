# Project content

The public portfolio currently uses concise summaries in `index.html`. The three `projects/<name>/index.html` files only preserve old links; do not restore the previous case studies or diagrams by editing those redirects.

For this version, each project needs a clear problem, my contribution, an accurate status and an evidence or contact link. Keep technical detail in the project's repository unless a dedicated page adds useful evidence. Add screenshots or outcome metrics only after checking they are shareable and substantiated.
